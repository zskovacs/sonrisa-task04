# Prompt history

This directory records final English prompts for material coding-agent work **after the repository bootstrap task**. The bootstrap/context prompt is excluded and must not be stored here. No numbered prompt has been executed or recorded as part of this baseline.

Follow [AGENTS.md](../AGENTS.md#2-prompt-history). Use sequential filenames such as `001-analyze-requirements.md`, `002-design-event-model.md`, and `003-review-architecture.md`, including material delegated prompts. Save the final prompt before sending it; preserve it verbatim in a clearly delimited section.

Optional metadata must be separate from the prompt: purpose, date, milestone, execution status, outcome, validation, and corrections/rejections. Do not silently rewrite an executed prompt. A material follow-up or corrected prompt gets a new number and a link to its predecessor. Finalize prompts without secrets before execution so the recorded version can be exact and safe.
